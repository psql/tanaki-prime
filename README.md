# 🍜⚙️ Tanaki Prime

> Part of the **TanakiOS Character Bible** · [Lingonberry Organisation](https://lingonberry.org)

**Work-in-progress embodiment implementation of
[Tanaki Lingonberry](https://github.com/psql/tanaki).**

The character itself (the soul: principles, practice, bible) lives in
[psql/tanaki](https://github.com/psql/tanaki). This repo is the **body**: the
heavy production assets that give the spirit physical form. It is derived from
Tanaki and carries his complete original history inside it.

## What lives here

- `rig/` : the Blender rig and its versions
- `animation/` : animation work, archive, and exports
- `paint/` : paint and images
- `control-net-references/` : reference sets
- `props/`, `sfx/`, `static-img/`, `vector-art/`, `watermarks/` : the rest of
  the physical kit
- `input/`, `output/` : working audio and previews
- `figma-plugin/`, `utilities/` : tools for working on the body
